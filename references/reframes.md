# 画像怎么写

用途：写报告正文（名字、一句话、最意外的一点、发动机、本事、底色、要留意）。
原则只有一条：**只放结论**。用户答完题想要的是被看懂，不想看推导。题号依据全部写进 `evidence`，报告会把它折叠在最后。

## 一、先找线，再下笔

1. 打开 `score` 的 `profile`：`engine`（发动机）、`skills`（本事）、`drain`（耗你的事）。
2. 一条结论至少 3 个选择指向同一处，并且横跨两类以上的题：
   - 情境题（遇事第一反应）
   - 小时候（十岁玩什么、大人怎么说你、上学时主动做什么）
   - 别人眼中（朋友找你干什么、第一个想到你的时候、听得最多的夸奖）
   - 来劲（忘了时间、做完更有精神、怎样算值了）
   - 想用（最近手痒、用得太少）
3. 优先用 `level: 明显` 的项。随机作答也会冒出 1 到 2 个“明显”项，所以跨题型这一条不能省。
4. 风格四个方向（开拓/深耕、人/物、快/长、独/合）用来决定“这个人在什么时候、以什么方式最亮”。

## 二、每一块怎么写

**名字（portrait.name）**：2 到 5 个字，像一个角色，不是形容词。
- 好：定调者、翻译官、拆解师、点火的人、收尾王
- 不好：有主见的人、沟通达人、全能型选手

**一句话（portrait.line）**：两句以内。第一句写 TA 在什么时候最亮，第二句写 TA 之后更想做什么（或不想做什么）。
- 例：新事刚起头、大家还在绕的时候，你能拍板定方向，一句话讲清楚，让人愿意跟上。然后你想去开下一个头，而不是留下来催进度。

**最意外的一点（surprise）**：1 到 2 句，挑最反直觉的一个对照：
- 别人眼中的你 vs 让你来劲的你（例：你的判断力一直只用在私聊里；可真正让你来劲的，是让判断被很多人听到）
- 被夸的 vs 真正喜欢的（例：大家夸你会照顾人，可真正让你来劲的是把事讲明白）
- 自认的风格 vs 实际的选择

**发动机（engine）**：1 到 2 句，说清满足感从哪来。写成一个画面，不列能力名。
- 例：你把判断说出来，事情就朝那个方向动了。这是你做事最大的满足感来源。

**本事（skills）**：2 到 5 条，短名字 + 一句话。名字用大白话（拍板、讲清、看懂规则、收拾得体面），不用脚本里的能力名原文。同时是发动机的标 `engine: true`。可以加一句 `skills_note` 区分“发动机”和“只是本事”。

**底色（roots）**：2 到 3 句，结构是：成长环境 → 给了你什么 → 哪一点是你自己的。
- 不出现“水土”“风水”，用“你在一个……的环境里长大”。
- 只说环境给了你什么，不评判家庭和长辈。
- 最后落到一个“你自己的”东西上，例如：在讲究“别人会怎么看”的环境里还被说“有主见”，这股劲是你自己的。

成长环境的几种样子（内部名字 → 正文可以怎么说）：

| 内部名字 | 正文说法 |
|---|---|
| 稻田 | 安稳、热络、处处要顾着别人 |
| 小院 | 安稳，家门里自成一片天地 |
| 渡口 | 变动多，但身边一直有一张人情网 |
| 码头 | 来来往往、常有变数，要靠自己很快站稳 |
| 大院 | 不紧不慢，人情很浓，大家看着彼此长大 |
| 街角 | 不紧不慢，人情不远不近 |

**要留意（watch）**：1 到 3 条，每条一句话，只说容易卡在哪，不给对策。来源通常是风格组合（开拓 + 快反馈 → 起头多收尾少；独立 + 自己扛 → 不开口求助）和 `drain`。

## 三、写完自查

- 每句话换一个答案很不一样的人，还成立吗？成立就删。
- 正文里有没有题号、“我推测”“因为你选了”？有就删，挪进 `evidence`。
- 有没有“建议你……”“可以试试……”这类行动建议？有就删。
- 每条结论在 `evidence` 里都能找到至少 3 个选择吗？
