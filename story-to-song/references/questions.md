# 小白版提问

目标：拿到能写成词的具体材料。**不问曲风、不问乐理。**

## 原则

- 一次最多 3 个问题，能给选项就给选项。
- 用户已经讲过的，不要再问。
- 用户说得模糊，追问**一个具体场景**，不要追问道理。
- 用户说"你自由发挥"：不调知识库，按 `rules.md` 直接写，并在注解里说明哪些是你的设定。
- 用户没说 TA 的性别，词里就用"你"，不要根据名字或关系去猜，也不要问；用户用了"她""他"，按用户的。
- 用户答不出"发生了什么"：走下面「没有具体事件的用户」，不要追问事件，也不要替他编。

## 第一轮：场景、对象、事

1. **这首歌属于哪一种？**
   - 怀念 / 释怀（想一个人、放下一件事）
   - 暗恋 / 心动（说不出口、小心翼翼）
   - 生日 / 祝福（送给某个人）
   - 道歉 / 感谢（对某个人说对不起或谢谢。追问：对不起的是哪一件事 / TA 做过的哪件小事你还记得）
   - 亲情（写给父母、祖辈、孩子、兄弟姐妹。追问：TA 在世吗？哪件小事你还记得？）
   - 纪念 / 求婚（结婚纪念、恋爱纪念、求婚。要问一句：在什么场合给 TA？当面求婚 / 纪念日发给 TA / 婚礼上放）
   - 都不是（请用一句话说）
2. **写给谁？** 一个朋友、家人、恋人、一个公众人物、自己。
3. **发生了什么？** 一两句就行。

## 第二轮：挖具体的东西

好词靠具体的东西。从下面挑 2–3 个问：

- **一个画面或物件**：窗台、一件衬衫、一道菜、一条路、一张合照
- **一句话**：对方说过让你一直记得的；或者你一直没说出口的
- **一个细节**：季节、天气、时间、味道
- **一个动作**：当时在做什么，或现在回想起来会做什么

用户答不出来时，给二选一帮他想，例如："更像一个下午，还是一个深夜？"

## 第三轮：定感觉

只问一个：**希望别人听完这首歌，心里是什么感觉？**

| 用户的话 | 对应方向 |
|---|---|
| 难过但放下了、淡淡的 | 克制，近乎说话，不推高潮 |
| 想念、想哭 | 抒情，副歌可以更满 |
| 暖、开心 | 轻快，句子短，画面亮 |
| 不甘心 | 先压后放，Bridge 做转折 |
| 偷偷喜欢 | 小心、停顿多，句尾留白 |

要出歌时，这个答案也用来选 Suno / 海绵音乐的曲风档：难过但放下 → 档 B（安静民谣）；想念、想哭 → 档 A（中速抒情）；暖、开心 → 档 A 调快一点；不甘心 → 档 C（影视感）或 A。

## 没有具体事件的用户

用户只想"给某个人写首歌"，说不出发生了什么。不是没材料，是觉得日常碎片"不算故事"。改问碎片，一次最多 3 个，能给选项就给选项：

1. **写给谁，想让 TA 听完是什么感觉？** 关系写一个就行；感觉给选项：生日 / 想念 / 谢谢你 / 对不起 / 偷偷喜欢 / 纪念 / 求婚 / 其他。
2. **关于 TA 的一个小碎片（三选一回答）**：一个小动作或口头禅 / 常在一起的地方或时间（一顿饭、一条路、一个傍晚）/ 一样和 TA 绑在一起的东西。
3. **一句想对 TA 说、但平时没说的话。** 哪怕很短，比如"你别太累"。这句话做副歌钩子。

两个碎片加一句话就够写。答不出就给二选一。方向确认照常做（见 SKILL.md 第 4 步）。

**写法（通用歌）**

- 事实信息接近 0。**不编"发生过的事"**：对象是真人，用户会把这首歌当真话送出去。
- 画面优先用用户给的碎片，其余用通用日常（灯、饭桌、天气、一条回家的路）和"我"的动作。这些画面不声称真的发生过。
- **不替 TA 编新动作、新话。** TA 只有用户给的那一个细节。
- 钩子用那句话，三遍副歌靠**位置变化**推进：心里说 → 说一半 → 说出口。
- **留一行填空**：把用户给的细节放进主歌的一句里，在注解里标"可替换"，并告诉用户换的时候句尾要保持原韵。
- 配比参考：事实 0–5%、画面 25–35%、写意 60–70%（见 `rules.md` 第七节，这个区间没有直接样本）。
- 注解里分开标：**用户给的** / **我设的通用画面** / **我设的"我"的动作**。

```
- 一句话（说过的/没说出口的）：
- 想要的感觉：

## 已核实的事实（来源）
-
## 想象的部分

```
