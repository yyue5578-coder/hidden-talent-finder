# 写词规则

写词时按这份规则做。能用脚本检查的写明了"脚本会查"，其余靠自检。

## 一、结构

- 常见布局：主歌 1 → 主歌 2 → 副歌 → 主歌 3 → 副歌 → 桥段 → 副歌 → 尾声。
- 主歌 4 句，副歌 4–8 句，桥段 4 句。预副歌可选，用于从叙述转向情感。
- 总字数 250–420，对应 3–4 分钟的慢歌。慢歌字数太多，歌手只能加快吐字，听上去像"编曲在抒情，嘴巴在赶路"。（脚本会查）
- 有一段**不唱**的留白（吟唱、念白、尾声）会让歌更有余味，但最多一两处。

## 二、韵脚

**先规划，再写。** 先定全曲的韵脚方案，写进创作注解：`主歌 an → 副歌 i → 桥段 ou`。

- 每段内韵脚统一，**换韵只在段与段之间**。
- 段内押韵率：默认 ≥80%；民谣、叙事类慢歌 ≥60%（脚本用 `--min-rate 0.6`）。
- 这些韵母在现代听感里不押，**同一段内不要混用**：an/ang、en/eng、in/ing、ong/eng。（脚本会查）
- i 与 ü 按同一辙（一七辙）处理。
- 拿不准时朗读：听不出押韵就不押。
- 开口韵（ao、an、ang、ong）偏明亮大气；闭口韵（i、ü、in、ing）偏内敛细腻。按情绪选。
- 句尾字重复（如两句都收在"你"）算押韵，但要是有意的，并在注解里说明，否则像词穷。

## 三、句长与节奏

- **单句不超过 11 个字**，超过的在气口处拆开。（脚本会查）
- 主歌内部句长波动控制在 ±3 字。
- 副歌可以有 1–2 句拉长做爆发，前后要有短句收束。
- 预副歌的句子比主歌短，制造加速感。
- 桥段最自由：短句和长句交替都行。
- 如果用户说"词太多"，先诊断，不要直接砍字：
  1. 一句里装了两个意思 → 拆成两句
  2. 句子是叙述而不是画面 → 把叙述换成画面（"孩子的作业还没签完" → "作业本摊开在深夜"）
  3. 真的字多 → 删虚词（了、的、个），合并列举

## 四、钩子

- 副歌第一句是全曲的记忆点。
- 钩子或副歌核心句出现 **3 次以上**，每次要推进一点，不能只是原样重复。（脚本会列出重复 3 次以上的句子）
- 三遍副歌的推进，可以是：认知变化（"我以为……" → "其实是我……" → "这一次我来说"），或位置变化（同一个词，从句尾 → 手里 → 句外）。
- 如果主歌 → 副歌只是换了说法（"我想你" → "我真的想你"），说明没有推进，必须改。
- 案例里最常见的推进办法（来自 17 首拆解）：**同一个句架，每遍只换一个词**（换动词、换宾语、换人称），或**同一个称呼，每遍换一个问题**。比"每遍加一层情绪"更稳。
- 副歌原样重复 3–4 遍的歌也存在（如《后来》），但它们靠别的东西撑住（得失对照、天气意象、桥段转折）。小白不要只学"重复"，不学"撑住的东西"。

## 五、意象与画面

- **每一段至少有一个具体的东西**（名词 + 动词）：窗台、衬衫、拖鞋、一条路、一盘菜。
- **能用动作，就不用情绪词。** 
  - 直白（结论）："我很难过"
  - 动作（证据）："听完没关 坐到很晚"
  - 找法：问"一个人在这种感觉里，手上会做什么？"
- 同一个意象可以前后呼应（前面的"窗"，后面换成"门"），不要每段都换新意象。
- **歌名点题，词里不点破。** 如果歌词里直接说出比喻（"你是我的逗号"），听的人只能点头；把它拆成动作，让听的人自己听出来。

## 六、AI 味（脚本能查前几项）

| 现象 | 处理 |
|---|---|
| 同一段出现 2 次以上"像……一样" | 换成直述或动作 |
| 同一段出现 2 个以上同义情感词（心痛心碎心酸） | 只留 1 个，其余换成动作 |
| 副歌只是主歌换了说法 | 必须推进 |
| 结尾出现"永远""永恒""无尽" | 换成具体画面或一个没做完的动作 |
| 一段里有 2 个以上四字成语 | 用口语短句替代 |
| 连续 3 句以上结构相同 | 变换句式（倒装、省略、反问）；如果是有意的排比，在注解里说明 |
| 用了"宛如""缱绻""蓦然"等 | 除非是国风，否则换成口语 |
| 抽象词（回忆、岁月、青春、时光） | 换成一个具体的东西 |

## 七、真实人物与事实

- 涉及真人真事，先联网查证，把已查实的和想象的分开记录。
- 搞清楚"在哪里说的"（采访、微博、歌里）和"怎么知道的"（亲眼所见，还是别人转述）。场景和渠道写错，整首歌会失真。
- 只用公开信息，不推测私下对话和心理。想象的部分用"我想""我猜"，不写成事实。

### 真人题材规矩（事实 / 想象 / 含蓄）

先分清两条轴，别混在一起：**真实 vs 想象**问"有没有依据"，**含蓄 vs 直白**问"怎么说"。含蓄是写法，不等于不真实。

**1. 事实分三档，写前先分好，记入故事笔记**

| 档 | 处理 |
|---|---|
| 多个独立来源一致 | 可以写进歌里 |
| 只有单一来源（尤其是标"AI 生成"的转载） | **不入歌**，最多留在笔记里 |
| 来源互相矛盾 | **不写**，歌里绕开，不选边 |

**2. 事实 / 画面 / 写意的配比（区间参考，不是硬指标）**

每句归一类：

| 类 | 含义 | 例 |
|---|---|---|
| 事实信息 | 交代发生了什么、谁、何时、什么关系，没有画面 | 一起住了四年、你走了 |
| 画面 | 能看见、听见、摸到的物件、动作、天气 | 落在裙子上的花瓣、下课铃声 |
| 写意 | 比喻象征、情绪直述、议论、愿望、抒情提问 | 青春是旅行、愿你平安 |

区间来自对 17 首样本（怀念、暗恋、生日各几首）的逐句统计（见 `knowledge_base/配比统计.md`），其中有人物和场景的 8 首约为 **事实 12% / 画面 34% / 写意 54%**。写人物故事时，按下面的区间靠：

| 范围 | 区间 |
|---|---|
| 全曲 | 事实信息 10–15%，画面约 30%，写意约 55% |
| 主歌 | 画面加事实合计约 6 成 |
| 副歌 | 画面加事实合计约 2–3 成，其中事实尽量 0–1 句 |
| 无故事的歌（用户没给事件） | 事实 0–5%，画面 25–35%，写意 60–70%（没有直接样本，按暗恋、生日两类推算） |

几条使用方式：

- **画面句要多于事实句。** 事实比画面多，多半是写成了时间线，检查一下是不是流水账。
- 事实只当骨架：交代"谁、多久、发生了什么"就够，细节交给画面。事实句尽量写得朴素直接（"四年""十八天"），不要为了含蓄把事实写模糊。
- 副歌负责情绪，不负责交代经过。
- 这是区间，不是指标，偏离一些没关系；区间只来自当初那 17 首（知识库现在有 38 首，更新后的统计见 `配比统计.md`，区间没有重算），暗恋、生日两类缺典型歌，参考价值低。风格特别的歌（对照结构如《十年》，纯抒情如《真心英雄》）可以偏离，但要在注解里说明为什么。
- 不是真人题材也可以用这个区间检查一首歌是不是太"空"（全是写意）或太"账"（全是事实）。

**3. 想象只能写这几样**

- 叙述者自己的动作和感受（没追上前、手攥紧又松开）
- 不涉及具体人和事的环境画面
- 以上必须写成动作，不写成"我很愧疚"这类情绪结论

**4. 想象不能写这几样**

- 替对方（歌里的"你"、或第三人）写心理、原话、反应
- 对关系或事件下结论（"误会解开了""终于和好"）
- 编造具体事件（时间、地点、谁对谁做了什么）
- 把"推测的原话"写成引语，除非注解里标明是想象

**5. 注解必须有「事实 / 想象对照表」**

每一句都标：事实（来源几个）/ 事实+想象 / 想象 / 边界。表后写两行统计：真假维度（事实 N 句，事实+想象 M 句，想象 K 句），和配比维度（事实信息 / 画面 / 写意各占几句、几成，对照第 2 条的区间），再列出"没有写进歌里的"。

**6. 发布标注**

简介写明：粉丝二创｜AI 辅助创作｜歌中"我"的心情为想象，非当事人原话。未了结的事写明"不下结论"。

**7. 写给身边的普通人（同学、同事、朋友、家人）**

- 不在歌名、简介、封面里写全名、班级、学校、单位。
- 不替 TA 编新动作、新话，TA 只有用户给的细节。
- 用户没说 TA 的性别，词里用"你"，不用"他""她"去猜；用户用了就照用户的。

## 八、输出格式

`歌词定稿.md`（只放歌词）：

```
[Verse 1]
……

[Chorus]
……
```

- 标签用英文方括号：`[Intro] [Verse 1] [Pre-Chorus] [Chorus] [Bridge] [Interlude] [Outro]`。
- 念白、吟唱段，在标签下一行用括号写表演提示，如 `(spoken, almost not sung, no melody)`。脚本会忽略整行括号。
- 不放注解、不放校验表。那些写进 `创作注解.md`。

`创作注解.md` 包含：创作方向、韵脚方案（每段韵组 + 押韵字）、用了哪些技法、想象与事实的对照、校验脚本输出。
