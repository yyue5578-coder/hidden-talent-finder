# 打磨：事实核对、诊断问题、直白→动作

## 一、事实核对（涉及真人真事时必做）

1. **联网查证**：搜公开报道，不要凭印象写。
2. **搞清场景**：这件事是在哪里说的（采访、社交平台、歌里）、谁说的、什么时候。
3. **搞清渠道**：当事人是亲眼所见，还是通过别人才知道？这决定歌词的视角。例如"二手消息"和"晚了几年才知道"是两回事，前者是渠道，后者是时间。
4. **只写公开信息**：不推测私下对话、心理活动、动机。想象的部分，写成"我想""我猜"。
5. 在 `故事笔记.md` 里分开记：**已核实的事实（附来源）** / **想象的部分**。

## 二、诊断问题

用户常常说不出"哪里不好"，所以不要问"满意吗"，由你来逐条检查并**主动指出**具体句子：

1. **这句话你平时会说吗？** 不会说的，多半是 AI 腔。
2. **有没有哪句在解释情绪？** 比如"我很难过""我们都没有错"。换成动作。
3. **有没有抽象词？** 回忆、岁月、青春。换成一个具体的东西。
4. **事实有没有错？** 回到故事笔记核对。
5. **有没有哪句太长，唱起来会喘？** （脚本会查）
6. **副歌三次是不是在推进？** 只是换说法，就是没推进。
7. **歌名点题了吗？词里有没有把比喻直接说出来？**
8. **整首歌是在讲一件事，还是塞了好几件？** 一首歌只讲一件事。

## 三、直白→动作对照

直白的句子是结论，动作是证据。

| 直白（结论） | 动作 / 事实（证据） |
|---|---|
| 我很难过 | 听完没关 坐到很晚 |
| 我们都没有错 只是走完了 | 往后的门 我不守 |
| 我想你当时一定很心碎 | 我想你那天 也没人劝 |
| 我还爱着你 | 要是有人喊你的名字 我先回头 |
| 我很想你 | 你最爱的那盘菜 后来成了我的日常 |
| 我很在乎你 | 你说过的路 我走了两遍 |

如果用户觉得某句"太俗"又说不出怎么改，问：**"如果这是你的一个朋友，他当时在做什么？"** 然后写那个动作。

## 四、"点题不点破"

| 点破（听的人点头） | 不点破（听的人自己听出来） |
|---|---|
| 你是我句中的逗号 | 我说话 后面总要带你 |
| 我把你的名字当成逗号 | 带得久了 就说成了语气 |

做法：歌名定下比喻，词里只写动作和细节，让听的人自己把两头接上。

## 五、落盘规则

- 每一轮修改后，立即覆盖 `歌词定稿.md`。
- 不保留"旧版/新版"并存的文件。旧版放 `旧版/`，文件名带日期。
- 用户说"回到最初那版"，从 `旧版/` 恢复，不要凭印象重写。

## 六、红线

- 涉及真实人物时，标"粉丝二创"或"虚构创作"；未了结的纠纷，不替当事人说话、不下结论。
- 不用真实歌曲名做歌名，尤其是当事人写过的歌。
- 不在提示词里写真实歌手名字。
- 写给身边的普通人（同学、同事、朋友、家人）时，不在歌名、简介、封面里出现全名、班级、学校、单位。
- 不涉黄、暴力、违法、政治敏感、仇恨言论。
- 发布时标注"AI 辅助创作"；不商用，除非用户已确认词曲版权与平台条款。
