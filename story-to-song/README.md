# 故事成歌（story-to-song）

给零基础的人用的中文写歌 skill：从一个故事或一句想说的话，到一首能写进 Suno / 海绵音乐的歌词和提示词。一个 skill 走完，不需要懂乐理，也不需要会写词。

## 能做什么

1. **提问**：按场景和感觉问，一次最多 3 个问题；用户没有具体事件时问小碎片，不替用户编。
2. **核实事实**：写真人真事时联网查证，事实分三档（多源一致 / 单一来源 / 互相矛盾）。
3. **写词**：先定场景、80 字方向确认、规划韵脚，再逐段写。
4. **校验**：`scripts/check_lyrics.py` 检查押韵、句长、字数、AI 味、多音字读音风险。
5. **打磨**：主动指出可能不像人话的句子，按用户反馈只改被指的地方。
6. **出提示词**：Suno 和海绵音乐，先问男声还是女声，不按姓名推断性别。
7. **生成后检查**：只听三处，只局部重做。

## 覆盖的场景（`knowledge_base/`）

怀念/释怀、暗恋/心动、生日/祝福、纪念/求婚、道歉/感谢、亲情。共 38 首单曲拆解和 6 份场景规律。**每份场景规律顶部写明可信度**，样本不足的场景会告诉用户。

单曲文件只存分析，每首最多引用 3 句关键句，不存全词。

## 目录

```
story-to-song/
  SKILL.md             工作流入口
  references/          写词规则、提问、打磨、迭代、Suno、海绵音乐、生成后检查
  knowledge_base/      场景规律、单曲拆解、配比统计
  scripts/             check_lyrics.py（需要 Python 3；读音检查用 pypinyin）
  templates/           创作注解模板、单曲拆解模板
```

## 使用

把 `story-to-song` 目录放进你的 agent 的 skills 目录（如 `~/.claude/skills/` 或 `~/.workbuddy/skills/`）。校验脚本：

```
python3 story-to-song/scripts/check_lyrics.py 歌词定稿.md --min-rate 0.6
```

## 提醒

- 写真人真事的歌，要标"粉丝二创 / AI 辅助创作"，不替当事人下结论、不编对方的心理和原话。
- 知识库里的作曲人、发行日期、获奖年份等背景信息，部分来源之间有冲突，单曲文件里已标注"未核实"。
- 配比区间来自早期 17 首样本，是一遍人工分类，只当参考。
- 海绵音乐的提示词细节尚未实测。
